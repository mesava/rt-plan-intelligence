# RT Plan Intelligence — публичная демоверсия

Статический одностраничный сайт (без бэкенда, сборщика и пользовательской загрузки файлов). Все планы создаются только в браузере и являются синтетическими.

- Интерактивная визуализация апертур MLC по CP
- Синтетические метрики Aperture Area, SAS5 proxy, Leaf Travel и MCSv/LSV/beamAAV
- Никакого парсинга DICOM и измеренного QA
- Не предназначен для клинического использования

Сайт лежит в `web/` и может быть развёрнут как статический проект на Vercel. Основное Python-ядро расположено в `src/rtpi` и остаётся независимым.

Для проверки локально откройте `web/index.html` в браузере. Формулы на веб-демо иллюстративные и требуют сверки с Python-реализацией перед любым применением к реальным RTPLAN.

## Расчёт MCSv / LSV / beamAAV

Код: [complexity.js](complexity.js). Проверка без браузера: `node --test web/test_complexity.cjs` (из корня репозитория).
