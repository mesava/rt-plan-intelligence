# Политика безопасности RT Plan Intelligence

## Статус

Проект v0.1.0 является **исследовательским прототипом** и **не является медицинским изделием**. Он не предназначен для клинического допуска дозиметрических планов.

## Конфиденциальность

- Никогда не публикуйте клинические RTPLAN, RTDOSE, RTSTRUCT, XCC, PDF, логи ускорителя, данные пациентов или ключи доступа в issues/PR, GitHub Actions или публичных демо.
- DICOM UID, приватные теги, BeamName и другие поля могут косвенно идентифицировать пациента; простое удаление PatientName недостаточно для деидентификации.
- Данные реальных пациентов разрешается обрабатывать только в защищённой локальной среде и в соответствии с правилами учреждения.
- Публично размещённый Streamlit принимает файлы на сервере. Для публичных демо используйте **только синтетические данные**.
- MVP по умолчанию не сохраняет загруженные файлы на диск, но **это не доказательство безопасности публичного хостинга**.

## Как сообщать о проблемах

Если обнаружена проблема, способная вызвать раскрытие медицинских данных или серьёзную ошибку расчёта, **не публикуйте реальные файлы или персональные данные в открытой issue**. Свяжитесь с владельцем репозитория через приватный канал или механизм GitHub Security Advisories (если доступен). Для воспроизведения используйте синтетические тестовые примеры.

Независимая валидация метрик, анализ угроз и дополнительные средства защиты должны быть выполнены до любого развёртывания с реальными клиническими данными.
