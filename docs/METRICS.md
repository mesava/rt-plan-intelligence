# Метрики v0.2 (исследовательские): определения и ограничения

**Только плановые данные DICOM RTPLAN MLCX.** Все расстояния в миллиметрах на уровне изоцентра, площади в мм². Эти показатели не измеряют gamma и не доказывают доставляемость.

| Поле | Определение |
| --- | --- |
| `control_points` | Число CP на луч/арку |
| `monitor_units` | BeamMeterset из FractionGroupSequence, если задан |
| `aperture_area_mean_mm2` | MU-взвешенное по ΔCMW среднее площади апертуры после clipping по jaws; берётся конечный CP интервала |
| `aperture_area_cv` | SD площадей CP / mean площадей CP, без MU-веса |
| `leaf_gap_mean_mm`, `leaf_gap_median_mm` | Среднее и медиана положительных jaw-clipped зазоров открытых пар по CP |
| `sas5_mu_weighted`, `sas10_mu_weighted` | Доля открытых и экспонированных Y jaws пар со значением 0 < gap < 5 / 10 мм, взвешенная по ΔCMW конечного CP |
| `leaf_travel_total_mm` | Сумма модулей смещений всех лепестков обоих банков между соседними CP (в том числе вне jaws) |
| `leaf_travel_mean_per_transition_mm`, `leaf_travel_max_per_transition_mm` | Среднее и максимум суммарного движения за переход |
| `mean_cp_aperture_area_change_fraction` | Среднее |Aᵢ₊₁−Aᵢ|/(Aᵢ₊₁+Aᵢ) по переходам, где сумма площадей > 0 |

Расчёт площади пары MLCX:

`gap_i = max(0, min(right_i, xjaw_max) - max(left_i, xjaw_min))`

`height_i = max(0, min(y_upper_i, yjaw_max) - max(y_lower_i, yjaw_min))`

`area = Σ gap_i × height_i`

При отсутствии jaws по X принимается неограниченная X-область; по Y — полная высота MLC.

**Важные замечания:**
- SAS по конечному CP — это **приближение** динамической доставки, а не непрерывный интеграл и не обязательно SAS по литературной формуле.
- Total Leaf Travel учитывает лепестки вне jaws, поэтому сравнение с другими реализациями требует совпадения определения.
- `aperture_area_cv` **не является литературным AAV/MCS**. `mean_cp_aperture_area_change_fraction` **не является валидированным Temporal Aperture Variability**.
- Пустые/закрытые поля и нулевая ΔCMW могут давать `null`, а не ноль.
- Для расчёта **скоростей и ускорений** нужна достоверная временная шкала, которой одних CP недостаточно.
- MCSv / LSV / beamAAV реализованы в v0.2 с конкретным jaw-aware определением (ниже); XCC, RTDOSE/RTSTRUCT, gamma prediction и clinical QA verdict **не реализованы**.

## v0.2 — исследовательский MCSv / LSV / beamAAV (jaw-aware)

В этой версии применена **одна явно определённая версия** MCSv для динамических последовательностей CP (не универсальный стандарт для всех TPS/методик). Рекомендуемый ориентир по различиям определений: Gaudreault et al., *Medical Physics* (2025), https://doi.org/10.1002/mp.17961.

Обозначения: CP i, две банки A/B, пары лепестков с положительной jaw-clipped апертурой и высотой в Y-jaws, вес перехода ΔCMWᵢ = CMWᵢ₊₁ − CMWᵢ.

1. **LSVᵢ:** для каждой банки по отсортированным по индексу активным парам
   \`LSV_bank = 1 − mean(|x_(k+1) − x_k|) / (max(x) − min(x))\`;
   \`LSVᵢ = LSV_A × LSV_B\`. Для одинаковых позиций или <2 активных пар: LSV_bank = 1 по соглашению. Это конкретная jaw-aware реализация; альтернативные варианты учитывают иной состав лепестков.
2. **beamAAVᵢ:** площадь jaw-clipped апертуры CP i, делённая на площадь виртуальной объединённой апертуры по всем CP данного луча. Для каждой пары знаменатель использует \`max_CP(right_clipped) − min_CP(left_clipped)\` и максимальную jaw-exposed высоту этой пары по CP (с отсечением отрицательных зазоров).
3. **MCSv:** \`Σ [ ((LSVᵢ+LSVᵢ₊₁)/2) × ((beamAAVᵢ+beamAAVᵢ₊₁)/2) × ΔCMWᵢ ] / ΣΔCMWᵢ\`.
4. **\`lsv_cp_mu_weighted\`**, **\`aav_beam_cp_mu_weighted\`**: отдельно те же средние по концам интервала с весами ΔCMW.
5. **\`mcs_vmat_jaw_clipped\`**: итоговое значение MCSv для луча по данной реализации.

**Ограничения:** все показатели безразмерные (номинально 0–1). При <2 CP, нулевой общей ΔCMW или закрытой виртуальной апертуре результат \`None\` — *не ноль*. LSV закрытого CP условно равно 1, но MCS закрытого луча не вычисляется. В расчёт не входит время фактической доставки, transmission, tongue-and-groove и дозовая ошибка. Эти показатели **не равны** прежней метрике \`aperture_area_cv\` и не следует объединять их как одну AAV. Для клинического использования нужна независимая проверка на эталонных RTPLAN, включая разные MLC и jaws.


**Применимость:** импорт DICOM RTPLAN назначает `mcs_vmat_jaw_clipped = None` для последовательностей без изменения угла gantry между CP; для статических IMRT-полей следует разработать отдельный MCS с segment/MU-взвешиванием. LSV и beamAAV остаются геометрическими CP-описателями. Простая детекция gantry-angle является эвристикой и также нуждается в валидации.
