# Импорт QA из PTW XCC и VeriSoft PDF

**Версия Python v0.3 · Исследовательское ПО. Не предназначено для допуска планов.**

## Что делает импорт

Локальный инструмент сопоставляет файлы внутри числовых папок случаев: RTPLAN (.dcm), RTDOSE (_Dose.dcm), PTW (.xcc) и PDF-отчёт. Каждый тип файла должен встречаться ровно один раз. При пропуске или дублировании выставляется requires_review; автоматическое угадывание соответствия запрещено.

Из PDF с текстовым слоем извлекаются заявленные в отчёте GPR, failed percent, численность проверенных/прошедших/не прошедших точек, dose difference %, DTA mm, low-dose threshold %, её референс и критерий Gamma <= 1.0. Эти данные являются цитированием чисел из отчёта, **не независимым пересчётом gamma**.

Два режима референса для 10% low-dose threshold: calculated_volume_max и normalization_value. Это методически разные варианты; при анализе должны группироваться отдельно.

Из XCC извлекаются структура и метаданные измерения: число детекторов, число временных отсчётов, интервал, конец ряда и режим накопления. Сами дозы не публикуются и gamma из XCC не рассчитывается. Для реконструкции нужны калибровки, геометрия, привязка к рассчитанному распределению и определение алгоритма сравнения.

RTPLAN разбирается существующим MLCX-парсером, если формат поддерживается. Возвращаются только число лучей, CP и суммарные MU.

## Запуск в разрешённой локальной среде

Установка: python -m pip install -e ".[qa]"

Команда: rtpi-qa /secure/private-cases --output /secure/analysis/qa_private.csv

Без чтения DICOM: rtpi-qa /secure/private-cases --no-plan-metrics --output /secure/analysis/qa_private.csv

CSV содержит только числовой индекс случая, числовые характеристики и кодированные флаги качества. Исходные имена файлов, фамилии, PatientID и исходные пути не экспортируются. Однако **псевдонимизированный результат QA всё ещё является чувствительной информацией**, поэтому не размещайте CSV публично.

## Принципиальные ограничения

1. Совпадение четырёх файлов в одной папке ещё не подтверждает идентичность плана и измерения. Требуется отдельная проверка DICOM UID, BeamMeterset, машинных данных и времени измерений.
2. PDF без читаемого текстового слоя помечается pdf_text_empty_needs_manual_review_or_ocr. OCR не запускается автоматически.
3. Несколько результатов gamma в одном PDF считаются неоднозначностью; выбираемый результат не угадывается.
4. Несогласованность сумм passed + failed и evaluated сохраняется как флаг качества.
5. Наличие названия статуса доставляемости в предыдущих аналитических CSV не является независимой меткой QA. Если статус был построен из GPR, использовать его как признак прогнозной модели нельзя из-за утечки цели.
6. Вся обработка медицинских файлов должна выполняться в разрешённой среде в соответствии с правилами учреждения.
