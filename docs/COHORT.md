# Контроль неоднородности RTPLAN до анализа QA

**Research only, локальная обработка с разрешениями учреждения.** В публичной Vercel-версии нет клинической загрузки.

## Страты

| Поле | Источник | Интерпретация |
|---|---|---|
| nominal_energy_values_mv | CP.NominalBeamEnergy | Номинальное значение энергии в RTPLAN; не независимая проверка режима пучка |
| fluence_modes | Beam.PrimaryFluenceModeSequence.FluenceMode | DICOM STANDARD/NON_STANDARD и прочие, когда указаны |
| delivery_group | изменения CP.GantryAngle + Beam.BeamType | ROTATING_ARC / DYNAMIC_MLC_FIXED_GANTRY / STATIC_MLC_FIXED_GANTRY / UNDETERMINED |
| rotating_beams | наследуемые CP GantryAngle | Число лучей с изменением угла |
| machine_group | TreatmentMachineName | Локальная групповая метка M01..., исходное имя не экспортируется |
| patient_group | PatientID | Локальная групповая метка PG001..., исходный идентификатор не экспортируется |
| repeated_patient_group | Повторяемость PatientID внутри серии | Важна для групповой валидации и исключения утечки между train/test |
| dose_rtplan_uid_link | RTDOSE.ReferencedRTPlanSequence | match, mismatch или unverified — **только структурная ссылка**, не измеренный QA |
| dose_patient_id_link | PatientID RTPLAN/RTDOSE | Сверка ID внутри процесса, наружу передаётся только статус |
| site_label | Только проверенная ручная разметка | unknown по умолчанию; из PTV нельзя достоверно вывести локализацию |

Важно: `BeamType=DYNAMIC` сам по себе не означает VMAT; при неподвижном gantry это отдельная категория. `FluenceMode=STANDARD` — заявленное свойство DICOM, а не независимая физическая идентификация пучка. RTPLAN без заголовка DICM может быть валидным implicit-VR экспортом; допускается только после проверки Modality/SOPClassUID.

## CLI

`rtpi-cohort /path/to/numbered-cases --output /private/strata.csv`

Для пользовательской разметки предусмотрен локальный CSV `case_index,site_label` из ограниченного списка: unknown, brain, head_neck, thorax, breast, abdomen, pelvis, prostate, gynecologic, spine, extremity, other. Это ручная классификация, не автоматически подтверждённая диагнозом или RTSTRUCT. Имена и свободный текст запрещены.

Классификатор возвращает **только группы** и не экспортирует PatientID, PatientName, DOB, StudyInstanceUID, SOPInstanceUID или локальные пути. Связь план↔XCC всё ещё **не доказана** автоматически: XCC не предоставляет сопоставимую DICOM ссылку RTPLAN UID, PDF может ссылаться на другой экспорт, а совпадающая папка не является самостоятельной верификацией.

## Статистическая обработка

1. Всегда изучать состав выборки по энергии, режиму, методике и проверенной локализации.
2. Для одинакового пациента не разносить отдельные планы между обучающей и тестовой частями — группировать по patient_group.
3. Не использовать метрики, рассчитанные из GPR (например, статус «доставляем»), как независимые признаки.
4. Не объединять результаты gamma с разной нормировкой низкодозового порога, различным типом анализа или разным %/мм/threshold без отдельной оценки.
5. Малые подгруппы анализировать описательно, без заявлений о клинической предиктивной точности.
6. При отсутствии доверенной метки локализации оставить unknown и запросить проверенный источник, а не угадывать по названию PTV.

В репозитории только синтетические тесты, реальные планы и пациентские результаты не публикуются.
