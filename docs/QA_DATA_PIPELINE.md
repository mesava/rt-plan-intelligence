# Импорт QA и XCC (исследовательский v0.3 прототип)

**Безопасная граница:** клинические XCC, PDF, DICOM и CSV с идентификаторами обрабатываются только на защищённой локальной станции. Никаких реальных данных в GitHub, GitHub Actions, публичном Vercel, демонстрационных фикстурах или логах.

## Проверенный источник

В пользовательской рабочей папке Google Drive (доступной только через авторизованный аккаунт) структурно обнаружено 31 папка с четырьмя файлами на случай: RTPLAN DICOM, RTDOSE DICOM, PTW XCC XML, PDF QA. В корне присутствует CSV с ранее рассчитанными 58 полями. Ни одно исходное клиническое значение не включено в репозиторий.

В проверенном XCC XML PTW встречаются:
- \`Content/MeasData/Measurement/Time\`, \`Angle\`, \`Data\`;
- \`MeasurementPreset/IntervalTime\`, \`MeasTime\`;
- \`DetectorArray/DeviceStoreMode\` со значением \`DoseAccumulated\`;
- \`Data\` — Base64 массив из float32 little-endian (подтверждено на одном файле).

Для одного проверенного XCC было 763 последовательных кадра с шагом 0,2 c и 1 405 значениями детекторов на кадр. **Это лишь подтверждение кодировки конкретного файла** — не описание всех XCC и не валидация измеренной дозы. Для полноценной реконструкции нужны калибровка, геометрия и привязка ко времени/углу CP.

## Локальный импорт

\`from rtpi.xcc import read_xcc_metadata\` — возвращает структуру XCC и число детекторов без чтения имён пациентов, raw матриц или дозы в выходной результат.

\`from rtpi.qa import read_qa_pdf, parse_qa_text, cohort_summary_csv\` — извлекает только gamma/критерии из PDF текстового слоя и обезличенную сводку CSV. Для PDF без текстового слоя возвращается \`gamma_pass_percent=None\`; OCR здесь **не выполняется**.

\`\`\`python
from rtpi.xcc import read_xcc_metadata
from rtpi.qa import read_qa_pdf, cohort_summary_csv

print(read_xcc_metadata("Measurement.xcc").to_dict())
print(read_qa_pdf("qa-report.pdf").to_dict())
print(cohort_summary_csv("full_technical_analysis.csv"))
\`\`\`

## Контроль качества перед корреляциями

- **Не считать отсутствующий параметр gamma нулём**. В ранее подготовленном CSV присутствуют GPR всех 31 случаев, но \`dta_mm\` заполнено лишь для 6, \`dose_diff_percent\` — для 8, \`threshold_percent\` — для 10.
- Считать только полностью сопоставимые критерии: dose difference, DTA, low-dose threshold, reference/normalization, local/global, dimensionality и определение объёма оценки.
- **31 план не равен 31 независимому пациенту**: три пары записей имеют одинаковые ID; фактически 28 уникальных идентификаторов. Для статистики учитывать кластеризацию.
- Нельзя использовать прежнюю колонку \`modulation_complexity_score\` как эквивалент новой \`mcs_vmat_jaw_clipped\`, пока определения и исходные RTPLAN не сверены.
- Градации цвета PDF («Green»/«Yellow») отражают настройки отчёта, но не подменяют критерии внутреннего QA отделения.
- PDF-парсер не заменяет сверку оригинальных графиков и текста отчётов; неоднозначные PDF должны пройти ручную проверку.

## Чего пока нет

Извлечения *полной* XCC-дозовой матрицы и пространственной реконструкции флюенса, измеренной gamma на уровне сырых детекторов, независимой DICOM-сверки всех 31 случаев, клинически валидированной корреляции и автоматической безопасной загрузки с Google Drive.
