# Развёртывание веб-сервиса (исследовательский MVP)

## Публичная демонстрация

В v0.1.0 Streamlit запускается **в режиме синтетической демонстрации по умолчанию**.
Загрузка медицинских DICOM в этом режиме **отключена**.
Для публичного размещения можно использовать [Streamlit Community Cloud](https://share.streamlit.io/) или собственную инфраструктуру.

Основные шаги:

1. Откройте Streamlit Community Cloud и авторизуйтесь через GitHub.
2. Выберите репозиторий `mesava/rt-plan-intelligence`, ветку `main`.
3. Укажите основной файл приложения `app.py`.
4. Убедитесь, что платформа устанавливает `requirements.txt` (в нём `-e .[ui]`).
5. Публикуйте **только синтетическую демоверсию**; **не устанавливайте** `RTPI_ENABLE_LOCAL_UPLOAD=1` на публичном сервере.
6. После публикации проверьте синтетический пример и отсутствие загрузчика DICOM.

> Публичный исходный код не означает, что клинические входные файлы можно передавать на публичный сервер. Возможность загрузки реальных DICOM будет рассматриваться только после реализации полноценной защиты и разрешения со стороны учреждения.

## Локальный запуск с загрузкой DICOM

Для тестирования с **обезличенными** данными в доверенной локальной среде:

Linux/macOS:

```bash
RTPI_ENABLE_LOCAL_UPLOAD=1 streamlit run app.py
```

Windows PowerShell:

```powershell
$env:RTPI_ENABLE_LOCAL_UPLOAD = "1"
streamlit run app.py
```

В обычном режиме (`streamlit run app.py`) доступен только синтетический пример.

## Что пока отсутствует

- Серверная авторизация и разграничение доступа
- Полноценное DICOM-деидентифицирование

**Не размещайте сервис с включённой загрузкой данных пациентов в публичном интернете.**
